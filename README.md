## 一、这是什么

SPT Casino 是《逃离塔科夫》SPT 单机版的赌场合集模组：在游戏主菜单底部任务栏新增一个“赌场”选项卡，点开后进入牌桌大厅，可在四张牌桌之间选择。

| 牌桌 | 玩法 |
| --- | --- |
| 21点 | 与庄家对赌，支持要牌 / 停牌 / 加倍 / 分牌 |
| 德州扑克 | 无限注，对手是“赌场常客” |
| 轮盘 | 单零欧洲轮（37 格，每笔下注庄家优势 2.70%） |
| 老虎机 | 五个转轴、243 种线路，最高可达下注额的一千倍 |

全部使用仓库里的真实货币下注：下注金额从仓库扣除，赢利直接返还；仓库满了赢利会以邮件形式补发。1.2.6 起，**每个存档首次打开赌场会获得 1,000,000 卢布**（服务端记录，重装不会重复发放）。

## 二、汉化范围

- 大厅、首次欢迎卡、1.2.6 新增的“礼金卡”、四张牌桌的全部可见界面文字（按钮、下注、赔付表、中奖提示、统计、弹窗等）；
- F12 设置面板中的设置项名称与说明；
- 服务端返回给玩家的提示（余额不足、下注超限、礼金发放情况等）；
- **保持英文**（改动会破坏功能，故不翻译）：HTTP 路由（`/blackjack/ping` 等）、JSON 字段键、存档与配置键、资源与音效文件名（`table.png`、`slot-win.wav` 等）、BepInEx 控制台日志与调试输出。

汉化方式为**源码级修改并重新编译**，不是对成品 DLL 做字符串替换；对局逻辑、概率与金额计算**一字未改**。

## 三、本仓库相对原版的改动

除字符串汉化外，只有三处功能性改动，均与显示有关（详见 [`docs/zh-cn.md`](docs/zh-cn.md)）：

1. **中文字体** — `src/Casino.Shared/FontPick.cs`（新增）
   原版各牌桌是“借一个内存里的 TMP 字体”来绘制文字，在英文环境下借到的是不含中文字形的字体，中文会走全局回退字体链渲染，出现方块或黑字内部白色杂点。汉化版改为：在所有已加载的 `TMP_FontAsset` 中挑选一个**同时包含中文与拉丁字形**的成品字体作为主字体（例如中文界面常用的 FontReplace 所加载的字体），中文、数字、符号同字体同材质渲染；找不到时退回原版行为。

2. **轮盘界面自适应缩放** — `src/Roulette.Client/RoulettePanel.cs`
   轮盘与下注台布并排总宽 1859 单位，1080p 下每侧仅余 30 单位；在 16:10 等更窄的屏幕上原本会轻微溢出屏幕。现在整组内容挂在同一个容器下，按实际屏幕宽度围绕屏幕中心统一缩放（保持居中），宽度足够时不缩放。

3. **显示层映射** — 少数“同一个字符串既当按钮文字又当协议键”的位置拆成显示映射，协议本身不变：
   - 21点动作按钮：`Hit/Stand/Double/Split` → 要牌/停牌/加倍/分牌（发给服务器仍是英文动作名）；
   - 21点手牌结果：`Win/Lose/Push/Blackjack/Bust` → 赢/输/平局/21点/爆牌；
   - 扑克街名：`Preflop/Flop/Turn/River` → 翻牌前/翻牌/转牌/河牌；
   - 扑克动作回退标签：`Call/Check/Fold/Bet/AllIn` → 跟注/过牌/弃牌/下注/全下。

> 服务端程序集（`src/*.Server`、`src/*.Game`）**未做任何修改**。发布包中服务端 DLL 里的少量玩家可见提示（下注被拒、礼金发放）是发布流程中做定点汉化处理的，源码保持原样。

## 四、编译

客户端为 `net472`，且按原版要求**必须针对实际游戏安装编译**（插件会校验对 `spt-*` 的引用版本）：

```powershell
dotnet build src/Casino.Client/Casino.Client.csproj -c Release -p:SPTPath=<你的 SPT 安装根目录>
```

产物：`src/Casino.Client/bin/Release/Casino.Client.dll`

服务端为 .NET 10 类库，按原版方式构建（本仓库未改动其源码）。

## 五、安装

1. **前置**：游戏需已能正常显示中文（例如已安装 FontReplace 或同类中文字体方案），否则牌桌中文会显示异常；
2. 把发布包内 `BepInEx\plugins\Casino` 复制到 游戏目录 `BepInEx\plugins\` 下；
3. 把发布包内 `SPT_Runtime\user\mods\Casino` 复制到 游戏目录 `SPT_Runtime\user\mods\` 下；
4. 若安装过旧版独立的 Blackjack / Poker / Roulette 模组，请先移除，避免重复选项卡与补丁冲突；
5. 重启游戏与 SPT 服务端。

提示：首次进入赌场会看到欢迎卡；欢迎卡每个存档只显示一次，若要重现，删除 `BepInEx\plugins\Casino\seen.txt`。礼金由服务端记录，重装不会重复发放。

## 六、已知限制

- BepInEx 控制台中的日志与调试输出仍为英文（技术信息，不影响游玩）；
- 三个已退役的独立插件（`Blackjack.Client`、`Poker.Client`、`Roulette.Client`）不随包发布，其内部 F12 文案未汉化；
- 若游戏内缺少任何含中文字形的 TMP 字体，中文会回退到原版行为（显示异常）。
